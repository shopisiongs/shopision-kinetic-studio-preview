# Shopision Kinetic Studio — design preview

This is an independent design exploration, not the live Shopision website. It has no checkout, form submissions, tracking, or production links. The source of truth is `sites/shopision/concepts/kinetic-studio/` in `shopisiongs/aa-platform`.

The public preview is intentionally hosted separately from `go.shopision.com` and `dev.shopision.com`.

The hero artwork is a generated still with CSS camera drift; reduced-motion settings keep it stationary. It is not a rotating 3D model or a video.
